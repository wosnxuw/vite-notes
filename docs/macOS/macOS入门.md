### 键盘鼠标

首先在 设置 --> 鼠标，关掉鼠标加速度，并且让滚轮方向正常

但是这确实会令触控板的滚动方向也变反

这一点通过安装 mos 可以解决，mos 是一个免费开源软件

并且它有一个平滑滚动功能，感觉比 macOS 自己的滚动好使，因为它本身的加速度不合理

（mos 在 mac 被远程控制时，似乎滑动的速度容易失控）

然后键盘方面 macOS 的左下角是四个键

fn ctrl(⌃) option(⌥) command(⌘)

win 是 ctrl win alt

好，其中 command(⌘) 约等于 ctrl

ctrl(⌃) 约等于 Windows 下，右边那个 📃 键，作用似乎是按下时，按左键等于按右键，它唯一有用的点就是在 shell 里，它是结束命令的那个 ctrl+C

fn(🌍) 大概是切换 F 区 功能的键，默认情况下，不按 fn 时，是触发功能，比如亮度调节；按下 fn 并组合 fx 键，才会触发 fx，比如在 vscode 里运行命令

option(⌥) “切换/另一种选择”按住 Option 点击顶部的 Wi-Fi 图标，可以看到详细的 IP 和信号强度，而且可以和 command 构成组合键

如果你插入标准美式键盘，87 键那种，如果不做任何设置，那么它的右下角是三个键，从左到右，依次是：

ctrl command option

至于 fn，它被丢掉了，但是外接键盘，按下 fx 就直接是 fx 的效果，因此外接键盘也不具备调光功能

所以，需要在设置里把这几个键换个位置，至少顺序和 mac 上得一致

### 用 homebrew 管理软件

homebrew 是一个开源项目，然后它类似于 macOS 上的 apt 或者 dnf（并不是唯一的包管理器，还有其他的，比如 Nix）

以 homebrew 为例，它把软件分为两类，公式 Formulae（CLI/库）和 桶 Casks（GUI）

`brew install <name>` 安装 Formulae，诸如 Git

`brew install --cask <name>` 安装 Cask，诸如 Chrome

其中后者和从官网上下载 dmg 然后手动安装一样，安装位置都是 `/Applications`，macOS 上每一个 app 都类似于沙箱。

所以卸载的时候，一般也只能卸载掉沙箱，产生的数据其实不会被干掉

一个卸载范式是，先用一些 App 卸载器全部清理掉，然后再用 brew uninstall 忘掉

brew 的下载源分为大概两种，第一种是 brew 自建的服务器（存放一些经典软件），第二种是软链接到软件提供者的服务器（去 get 那个 dmg）

homebrew 下载的软件还有一个问题：macOS Gatekeeper 看到这些 App 带有 com.apple.quarantine，但缺少“用户已批准打开”的 flag，所以直接弹“移动到废纸篓”，不给正常的“来自互联网下载，是否打开”确认入口

这个事情，我的老 mac 会弹，但是新 mac 不行，然后 brew 有一个自动签名参数已经废弃了，所以让 AI 写了一个钩子，下载后自动签好

brew 还有一个问题：很多软件会自动升级（尤其是和 AI 相关的，一天一个版本）此时再用 brew 管理也没啥用了，软件它自己有自己的想法

### 桌面

在 Windows，我的习惯一般是一个桌面，上面堆所有的窗口，因为任务栏里，窗口可以重叠，鼠标放上去就有预显示，所以不会混。

但是 Mac 里，你一个 Chrome 开两个标签页，它底下也只有一个图标，没有预显示，你需要自己找

按`Command + Tab/`` 可以换应用，但是两个窗口同时弹出，很怪

值得注意的几个有效技巧是

（1）右键程序坞里的图标，如果是“对号”，则说明此窗口正在看，如果是“菱形”，说明被收起了

（2）control + 左右，来切换桌面，适用于打游戏/全屏窗口

（3）control + 上，显示所有窗口；control + 下，显示当前应用所有窗口（最有用的一集）
