### jsonl / ndjson

换行分隔 json

每一行是一个完整的 json 对象，行内不允许有换行符

### jsonc

允许携带注释，实际上有的 json 就叫 .json，仍有注释

### bson

MnogoDB 的二进制存储和传输格式

### ES6

ES6 是 2015 年的标准，后续是 ESNext

### mjs / cjs

cjs = CommonJS，用`require`在代码运行到此处时，再加载对象（类似 C++ dlopen()）

msj = ES Module/ ESM，用`import` `export`执行前就确定依赖关系，静态

package.json 的 "type" 字段，是全局开关——设为 "module" 就按 ESM 规则，否则按默认的 CJS 规则

### jsx / tsx

React 发明的东西，“在 JS 里写 HTML 标签”的语法糖
