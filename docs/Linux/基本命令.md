### 网络

#### 网络包

按照现代 Linux 网络技术栈来看，是有两个包

老包叫做 `net-tools`，包含 netstat、ifconfig、route

新包叫做 `iproute2`，包含 ss、if

很多现代发行版默认安装 iproute2，而不是 net-tools

所以：不是它没给你装 ifconfig，而是你的命令过时了，现在应该默认选 iproute2 包里的工具

#### ip 与 路由、诊断&恢复网络

ip 命令是 iproute2 包里的，所以推荐先尝试

`ip addr` `ip route` `ip link` （后面有没有 show 都行）

缩写为：`ip a` `ip r` `ip l`

#### 端口 --> 进程

关键命令：`sudo ss -tlnp | grep :22`

tlnp 是 --tcp --listening --numeric --process

numeric 就是不翻译，只现实纯数字信息，加快速度（否则 443 会翻译为 https）

建议是 sudo，不 sudo 也能跑，但是看不了以 root 启动的程序，然而很多程序就是在那里

备注：其实很多电脑不 grep 也行，你可以总的概览一下，因为 -tlnp，只看 TCP 协议、只看处于**监听状态**的程序（程序主动访问互联网不叫监听）

#### 防火墙

最底层，Linux 内核里的防火墙框架叫 Netfilter

iptables 是老的用户态命令，现代发行版基本上不需要管

一般来说，你就是用两个命令来管 **ufw firewall-cmd**

Ubuntu/Debian (UFW) ufw

RHEL/CentOS/Fedora (FirewallD)



#### DNS 管理

（我这里暂时只有 Ubuntu 的经验）

DNS 确实是在 `/etc/resolv.conf`，但是它现在是最终结果，你不应该直接写

通过`ls -l /etc/resolv.conf`，返回 `../run/systemd/resolve/stub-resolv.conf` 大概率它被 systemd-resolved 生成的本地 stub 配置管住

所以应该用 resolvectl status 查看状态
