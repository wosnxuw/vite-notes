# Windows权限模型、网络共享与电源排障

收集并整理在 Windows 系统下高频使用、但隔一段时间不碰又容易忘掉的五个实用专题：双机网线直连传大文件（APIPA 与凭据坑）、远程桌面（RDP）登录格式、Windows 四级权限体系、PowerShell 常用等效命令，以及休眠/睡眠自动唤醒排障。

---

## 一、双机传输大型数据集（网线直连 + SMB 文件夹共享）

当需要在两台 Windows 电脑之间拷贝几十上百 GB 的大型数据集时，不需要移动硬盘，甚至不需要有路由器或交换机，直接拿一根普通网线把两台电脑的网口捅上就能跑满网卡带宽。

### 1. APIPA（无路由器自动分配局域网 IP）

两台电脑用网线直接相连时，因为没有路由器里的 DHCP 服务器发 IP，Windows 的 APIPA（Automatic Private IP Addressing，自动专用 IP 寻址） 机制会自动介入：
- 两台电脑都会从保留网段 `169.254.0.0/16` 中各自随机挑一个不冲突的 IP 地址（比如我实测时一台分到了 `169.254.111.5`，另一台分到了 `169.254.174.197`，子网掩码均为 `255.255.0.0`）。
- 虽然没有默认网关，但它们已经处于同一个二层直连网段下，可以直接互相通信。

### 2. 开启共享与微软账号凭据大坑

1. 在提供文件的电脑（假设 IP 是 `169.254.111.5`）上，右键目标文件夹 $\rightarrow$「属性」$\rightarrow$「共享」，添加 `Everyone` 读取权限；
2. 在接收文件的电脑上，按 `Win + R` 打开“运行”，输入 `\\169.254.111.5` 回车；
3. **最容易卡住的“输入网络凭据”弹窗**：
   因为 Windows 默认在“网络和共享中心”里开启了“有密码保护的共享”，此时必须输入对方电脑的账号密码：
   - 如果对方电脑登录绑定了 Microsoft 微软在线账号：注意！此时在凭据框里填它本地的计算机用户名、或者填开机的 4 位/6 位 PIN 码是绝对登不进去的！必须填那台电脑绑定的 微软账号完整邮箱地址 + 微软账号的云端登录密码（哪怕此时两台电脑只插了网线、根本没有连外网，Windows 本地也缓存了微软账号密码哈希，离线照样能验证通过）。
   - 如果对方是纯本地离线账号：可以在 `cmd` 里敲 `whoami`，按返回的 `计算机名\用户名`（如 `desktop-b6mln8c\name`）配合本地开机密码登录。
4. 传完数据后如何彻底关闭共享：右键该文件夹 $\rightarrow$「属性」$\rightarrow$「共享」$\rightarrow$ 点击「高级共享」，把顶部的“共享此文件夹”复选框取消勾选即可。

## 二、Windows 远程桌面（RDP）的用户名填写规则

用 Windows 自带的远程桌面连接（`mstsc`）或者从 Mac 上用 Windows App 连过去时，逻辑与上面文件共享以及 Linux 的 `ssh username@ip` 类似，最容易填错的也是微软账号：

- **计算机**：填目标电脑的 IP 地址（局域网 IP 或 Tailscale 的 `100.64.x.x`）。
- **用户名**：
  1. 可以填对方 `C:\Users\`（用户目录）下面显示的那个实际短文件夹名字（不带 `desktop-xxx\` 前缀）；
  2. 或者直接填对方绑定的微软账号邮箱。
- **密码**：只要目标电脑绑定了微软账号，密码必须填微软账号的邮箱密码，绝不是平时锁屏界面敲的那个 PIN 码！（注：如果目标电脑买来后从没用“密码”登录过、一直只用 PIN 码，有时需要先在目标电脑的锁屏界面切换成“使用微软账号密码”亲自解锁登录一次，把密码凭据缓存写进本地 LSA，远程桌面才能连通。）

## 三、Windows 的四级权限体系与提权

Linux 下的权限模型很简单：普通用户 vs `root (UID 0)`。而现代 Windows（自 Windows Vista 引入 UAC 用户账户控制以来）在系统内部实际上划分了由低到高的 四个权限层级：

```text
普通标准用户 (Standard User)
  --> 管理员 (Administrator，触发 UAC 弹窗点“是”之后拿到的提升令牌)
        --> SYSTEM (LocalSystem，操作系统内核与后台核心服务的运行身份)
              --> TrustedInstaller (最高权限：Windows Modules Installer 服务专属，连 SYSTEM 和管理员都删不掉的核心系统文件归它管)
```

1. **UAC（用户账户控制）的双令牌机制**：
   从 Windows Vista 开始，就算你用管理员账号登录电脑，平时双击打开的所有程序默认也只运行在被阉割过的“标准用户令牌”下；只有当你右键选“以管理员身份运行”并在弹出的 UAC 窗口点确认时，系统才会把完整的 `Administrator` 令牌赋给那个进程。
2. 如何获取 `SYSTEM` 与 `TrustedInstaller` 权限？
   - 有时候你会发现，哪怕已经是管理员权限的终端，去改某些系统目录或注册表还是报错“拒绝访问”，因为它们的所有者是 `SYSTEM` 或 `TrustedInstaller`。
   - 获取 `SYSTEM` 权限最标准的官方工具是微软 Sysinternals 套件里的 `PsExec`：在管理员终端执行 `PsExec.exe -i -s cmd.exe`，弹出来的那个黑框就是货真价实的 `SYSTEM` 身份（敲 `whoami` 会显示 `nt authority\system`）。
   - **`TrustedInstaller`** 实际上是一个名为 `Windows Modules Installer` 的系统服务所对应的特殊安全主体（在特殊排障工具如 `NSudo` 或 `AdvancedRun` 中也可以借用该服务的令牌启动进程，但日常系统禁止普通上下文直接以该身份跑程序）。

## 四、PowerShell 与 CMD 高频命令速查

以前在 Windows 上习惯用 `cmd` 的老命令，切到现代 PowerShell（采用统一的 `动词-名词` 命名规范，支持打出 `Get-H` 按 `Tab` 自动补全命令和文件名）后，几个最常用的系统诊断命令对照如下：

### 1. 算文件哈希校验值（`Get-FileHash`）

在 Linux 里，不同哈希算法是不同的命令（`md5sum`、`sha256sum`）；而在 PowerShell 里，统一用 `Get-FileHash`，算法通过 `-Algorithm` 参数切换（不传参数默认算的就是 SHA256）：

```powershell
# 默认计算 SHA256 哈希
Get-FileHash .\openwrt.img

# 指定计算 MD5 或 SHA1
Get-FileHash .\openwrt.img -Algorithm MD5
```

### 2. 网络连通与本机 IP 查看

```powershell
# 1. PowerShell 版的 ping（返回结构化的延迟与可达状态表）
Test-Connection www.baidu.com

# 2. PowerShell 版的 ipconfig（查看所有网卡的 IPv4 与 IPv6 地址详情）
Get-NetIPAddress
```

看 IPv6 地址时的两个快速辨识常识：
- 凡是以 `fe80::` 开头的：是 Link-Local（链路本地内网地址），相当于 IPv4 里的 `169.254.x.x`，只能在当前局域网网线内通，出不了公网；
- 凡是以 `2408:`（联通）、`240e:`（电信）、`2409:`（移动）开头的：是运营商分配给你的 真实公网 IPv6 地址，只要防火墙放行，外网可以直接通过这个地址连进你的电脑。

### 3. 修复 U 盘或移动硬盘文件系统错误

U 盘拔插不当提示“需要格式化”或文件损坏时，在终端用 `chkdsk` 直接扫描修复文件系统元数据（假设 U 盘盘符是 `G:`）：

```cmd
chkdsk G: /f
```

## 五、休眠（Hibernate） vs 睡眠（Sleep）与半夜自动唤醒排障

### 1. 休眠与睡眠的本质区别

可以用动物过冬和过夜来直观区分这两个概念：

| 模式 | 状态图标 | 硬件通断电行为 | 恢复速度与特点 |
| :--- | :--- | :--- | :--- |
| 睡眠 (Sleep) | 🌙 月亮（度过一个晚上） | CPU 和硬盘断电，但内存条（RAM）一直保持通电刷新，桌面所有打开的窗口状态留在内存里 | 敲一下键盘 1 秒亮屏恢复；但如果期间家里停电（或笔记本彻底没电），内存数据丢失，等于强行断电关机 |
| 休眠 (Hibernate) | 🕒 钟表 / 休眠（度过整个冬天） | 系统把当前内存里的所有数据原封不动写成 C 盘根目录下的一个大文件（`hiberfil.sys`），然后整台电脑彻底断电关机（耗电量为 0） | 下次按主机电源键开机时，直接把硬盘里的镜像读回内存，几秒钟恢复关机前打开的所有软件窗口（默认开始菜单里被隐藏，需在「控制面板 $\rightarrow$ 电源选项 $\rightarrow$ 选择电源按钮的功能」里勾选开启） |

（注：Windows 里有两处改睡眠时间的地方——新版的「设置 $\rightarrow$ 系统 $\rightarrow$ 电源和睡眠」和老版控制面板的「电源计划 $\rightarrow$ 更改计算机睡眠时间」。这两处操纵的其实是底层同一个注册表项，在一边改了，另一边也会同步更新。）

### 2. 电脑刚点“睡眠”过两秒就自己亮屏醒过来的终极排障

台式机最让人崩溃的一个毛病是：晚上点完“睡眠”，风扇刚停转两秒钟（或者半夜三点），电脑突然自己轰的一声又亮屏开机了！

根因：Windows 默认允许鼠标微小抖动、键盘、尤其是 有线网卡收到局域网里的广播包/魔术包（Wake-on-LAN） 时把电脑从睡眠中唤醒。

不要靠猜，直接用管理员终端跑一条系统电源诊断命令，它会直接列出当前到底是哪几个硬件设备被授予了“唤醒电脑”的特权：

```cmd
# 1. 查看当前到底是哪几个硬件开启了“允许唤醒这台电脑”的权限
powercfg /devicequery wake_armed

# 2. 如果刚发生过莫名其妙的半夜自启动，直接查“上一次到底是谁把电脑弄醒的”
powercfg /lastwake
```

一劳永逸的解决办法：
看上面命令打出来的名字（通常就是你的有线网卡 `Realtek / Intel Ethernet Controller`、鼠标和键盘），右键「此电脑 $\rightarrow$ 管理 $\rightarrow$ 设备管理器」，找到对应的网卡、鼠标、键盘，双击点开「电源管理」选项卡，把“允许此设备唤醒计算机”前面的勾全部取消掉。禁掉之后（改为只允许按机箱物理电源键唤醒），睡眠就再也不会自己诈尸醒过来了。
