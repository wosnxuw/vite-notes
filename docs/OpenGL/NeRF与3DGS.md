# NeRF 与 3DGS 三维场景重建

三维视觉与神经渲染领域近年来最火的两代技术——2020 年的 NeRF（神经辐射场）与 2023 年的 3DGS（3D Gaussian Splatting，三维高斯泼溅）的核心原理对比与实操工具笔记。它们解决的是同一个问题：输入围绕一个物体或场景拍摄的多张 2D 照片（及对应的相机位姿），如何在计算机里重建出这个 3D 场景，并能从任意新的相机视角实时渲染出逼真的 2D 画面（新视角合成，Novel View Synthesis）？

---

## 一、NeRF（Neural Radiance Fields，神经辐射场）

NeRF 是 2020 年提出的技术。首先要明确：NeRF 本身是一套三维体积渲染与训练流程，而不是像 Transformer 那样指代某一个复杂的神经网络架构——事实上，NeRF 内部用到的神经网络极其简单，仅仅是一个普通的全连接多层感知机（MLP）。

### 1. NeRF 是怎么用神经网络“记住”一个 3D 场景的？

传统图形学（如 OpenGL）是用显式的三角形网格（Mesh）或点云来表示 3D 物体；而 NeRF 走的是 隐式表示（Implicit Representation）路线——它把整个 3D 空间里的几何与光影信息，全部压缩“背诵”进了一个 MLP 网络的权重参数里：

```text
输入 5D 坐标：空间中某一点的三维位置 (x, y, z) + 相机看向该点的二维视线方向 (θ, φ)
  --> 喂入一个多层感知机神经网络 (MLP)
输出 4D 属性：该空间点在该视角下的颜色 (R, G, B) + 体积密度 / 不透明度 (σ / alpha)
```

### 2. NeRF 是怎么渲染出 2D 照片并训练的？（体积渲染 Volume Rendering）

1. 当要渲染屏幕上某一个像素点的颜色时，从相机光心穿过这个像素往 3D 空间发射一条射线（Ray）；
2. 在这条射线上采样几十到上百个 3D 空间点，把每个点的 `(x, y, z, θ, φ)` 喂给 MLP，算出每个采样点的 `(RGB, alpha)`；
3. 沿着这条视线，把所有采样点的颜色按透明度权重做积分累加，就得到了最终显示器上这个 2D 像素的颜色；
4. 拿渲染出来的 2D 像素颜色和真实拍摄照片上的像素颜色算误差（Loss），反向传播更新 MLP 的权重。

NeRF 的致命痛点：
因为它是稠密（Dense）隐式表示，连空无一物的空气区域，射线穿过去时也必须在上面采样几十个点并挨个跑一遍 MLP 前向推理才能知道“原来这里是透明的空气”。渲染一张图要调几百万次神经网络，导致训练极其漫长，且实时渲染帧率极低。

## 二、3DGS（3D Gaussian Splatting，三维高斯泼溅）

2023 年发布的 3DGS 彻底抛弃了慢吞吞的 MLP 神经网络隐式查询，杀了一个漂亮的回马枪——重回图形学传统的 显式表示（Explicit Representation），一举实现了极速训练与 100+ FPS 的实时高帧率渲染。

### 1. 什么是“三维高斯椭球”与“泼溅（Splatting）”？

- **显式拟合场景**：3DGS 不再用神经网络去记空间，而是直接在 3D 空间里撒下几十万到几百万个带半透明度的 3D 高斯椭球体（3D Gaussians）。每个椭球都有自己明确显式存储的参数：
  1. 中心位置坐标 `(x, y, z)`；
  2. 决定椭球胖瘦、拉伸形状与旋转朝向的 3D 协方差矩阵（缩放 + 旋转四元数）；
  3. 不透明度 `alpha`；
  4. 表示不同视角下光泽颜色变化的球谐函数系数（Spherical Harmonics, SH）。
- **“泼溅（Splatting）”是什么意思？**
  这个词非常形象：想象你手里抓着一堆彩色的半透明软泥球（3D 高斯椭球），往一块 2D 玻璃屏幕（相机成像平面）上砸过去，每个 3D 椭球砸在 2D 屏幕上就会啪地摊开成一个边缘柔和渐变的 2D 彩色光斑。把屏幕上同一个像素位置叠在一起的若干个光斑按深度顺序混合起来，瞬间就拼出了一张极其逼真的照片！
- **怎么训练？**
  因为从“3D 椭球参数”投影“泼溅”到“2D 屏幕像素”的整套光栅化数学公式是完全可微分的（Differentiable Rasterization），所以根本不需要神经网络，直接用梯度下降算法去调整这几百万个高斯椭球的位置、形状、大小和颜色，并在训练过程中自动把过大的椭球分裂细化、把几乎全透明的无用椭球剔除掉。

### 2. NeRF vs 3DGS 的核心本质对比

| 对比维度 | NeRF (神经辐射场) | 3DGS (三维高斯泼溅) |
| :--- | :--- | :--- |
| 空间表达方式 | 隐式（Implicit）+ 稠密（Dense）：场景藏在 MLP 权重里，空间中任何一点（包括空气）都能查询其透明度，空气也必须靠采样计算出来 | 显式（Explicit）+ 稀疏（Sparse）：场景直接由物体表面那一群 3D 高斯椭球构成，空旷的空气区域压根没有椭球，训练中还会主动剔除透明椭球 |
| 渲染机制 | 沿每条像素射线密集采样，逐点跑 MLP 神经网络做体积积分（Ray Marching） | 直接用 GPU 硬件加速把 3D 椭球投影光栅化（Splatting）到 2D 屏幕，无需跑神经网络推理 |
| 训练耗时与渲染帧率 | 训练慢，实时渲染吃力 | 训练极快（数分钟级），轻松达到 100+ FPS 实时交互渲染 |
| 模型产物大小 | 极小（只是一个几 MB 到几十 MB 的 MLP 权重文件） | 较大（需要显式存几百万个椭球的参数，通常几百 MB 的 `.ply / .splat` 文件） |

## 三、开源工作站工具：Nerfstudio

如果想在自己带 NVIDIA 显卡的电脑上跑通从拍视频/照片到训练出 3DGS 模型的完整流程，目前 GitHub 上 Star 最多、工程化做得最完善的开源一站式框架是 `nerfstudio-project/nerfstudio`：

- 虽然名字还叫 `Nerfstudio`，但它早已集成了目前效果最好、速度最快的 3D 高斯泼溅实现——在它的启动命令里该方法名叫 `splatfacto`（即 `ns-train splatfacto --data <你的数据集路径>`），并自带了一个非常丝滑的 Web 3D 实时预览训练面板。
- **环境**：因为底层强依赖特定版本的 PyTorch、CUDA Toolkit 以及需要现场编译 C++/CUDA 自定义光栅化算子（`gsplat`）
